CAPSTONE TEAM PORTFOLIO — VERSION 1.0.0

INSTALLATION
1. In WordPress, go to Appearance > Themes > Add Theme > Upload Theme.
2. Select capstone-team-portfolio.zip and click Install Now.
3. Click Activate.
4. The theme creates starter pages and four placeholder team member profiles on activation. Existing pages and posts are not deleted.

CUSTOMIZE THE HOMEPAGE
Go to Appearance > Customize > Capstone Portfolio Homepage. Update the hero text, project title, project description, and contact email.

EDIT THE FOUR TEAM MEMBERS
Go to Team Members in the WordPress dashboard. Edit Member 1–4, replace the names, add each person's biography, set their role and skills in the Member Details panel, and upload a Featured Image for each person.

EDIT PAGES AND MENUS
Use Pages to edit About Our Team, Our Capstone Project, and Contact. Use Appearance > Menus (or Appearance > Editor, depending on WordPress configuration) to manage navigation. The theme also provides a simple default navigation if no menu is assigned.

NOTES
- Astra remains installed and can be reactivated if needed.
- Replace all sample names and text before publishing.
- Add a contact form plugin if you need a working inquiry form; the Contact page is editable and does not install a third-party form service automatically.
- Use a valid SSL-enabled domain before public launch.
